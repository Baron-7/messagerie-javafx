1. Introduction et objectifs du projet

Ce projet consiste à développer une application de messagerie instantanée similaire à WhatsApp, permettant à plusieurs utilisateurs de communiquer en temps réel via une interface graphique moderne. Il a été réalisé en binôme dans le cadre d'un projet de développement logiciel.

Objectifs principaux :
  • Mettre en œuvre une architecture client-serveur avec des sockets Java
  • Persister les données avec Hibernate/JPA sur une base de données MySQL
  • Concevoir une interface graphique réactive avec JavaFX
  • Gérer la communication asynchrone entre plusieurs clients simultanés
  • Implémenter des fonctionnalités avancées (fichiers, statuts, thème sombre…)

2. Architecture du système

L'application adopte une architecture Client-Serveur centralisée. Un serveur unique gère toutes les connexions et la base de données. Tous les clients se connectent à ce même serveur via des sockets TCP.

┌─────────────────────────┐ ┌─────────────────────────┐ │ CLIENT (Machine A) │ │ CLIENT (Machine B) │ │ ┌───────────────────┐ │ │ ┌───────────────────┐ │ │ │ MainApp.java │ │ │ │ MainApp.java │ │ │ │ LoginController │ │ │ │ LoginController │ │ │ │ ChatController │ │ │ │ ChatController │ │ │ │ MessageListener │ │ │ │ MessageListener │ │ │ └────────┬──────────┘ │ │ └────────┬──────────┘ │ └───────────┼─────────────┘ └───────────┼─────────────┘ │ Socket TCP (port 5000) │ Socket TCP └──────────────────┬─────────────────┘ ▼ ┌──────────────────────────────────────┐ │ SERVEUR (Machine A) │ │ ┌────────────────────────────────┐ │ │ │ Server.java │ │ │ │ (ServerSocket port 5000) │ │ │ └──────────────┬─────────────────┘ │ │ │ (1 thread par client)│ │ ┌──────────────▼─────────────────┐ │ │ │ ClientHandler.java │ │ │ │ (traitement des paquets) │ │ │ └──────────────┬─────────────────┘ │ │ │ │ │ ┌──────────────▼─────────────────┐ │ │ │ Services + DAO + Hibernate │ │ │ └──────────────┬─────────────────┘ │ │ │ │ │ ┌──────────────▼─────────────────┐ │ │ │ Base de données MySQL │ │ │ └────────────────────────────────┘ │ └──────────────────────────────────────┘

Fonctionnement du multi-threading

Pour chaque client qui se connecte, le serveur crée un nouveau thread (ClientHandler). Cela permet de traiter plusieurs clients simultanément sans blocage. Côté client, un thread dédié (MessageListener) écoute en permanence les paquets entrants du serveur.

Principe clé : Le MessageListener est le seul thread qui lit depuis le socket. Il redistribue ensuite chaque paquet : soit vers l'interface graphique (via Platform.runLater), soit vers une file d'attente (responseQueue) pour les requêtes synchrones (historique, liste des conversations…).

5. Base de données

La base de données MySQL est gérée par Hibernate (ORM). Les tables sont créées automatiquement au démarrage du serveur (hbm2ddl.auto = update).

Table users

ColonneTypeDescription
idBIGINT (PK)Identifiant unique auto-incrémenté
usernameVARCHAR (unique)Nom d'utilisateur
passwordVARCHARMot de passe (hashé)
avatarVARCHAREmoji avatar choisi à l'inscription
statusENUMONLINE / OFFLINE

Table messages

ColonneTypeDescription
idBIGINT (PK)Identifiant unique auto-incrémenté
sender_idBIGINT (FK → users)Expéditeur du message
receiver_idBIGINT (FK → users)Destinataire du message
contenuTEXTContenu textuel du message
date_envoiDATETIMEHorodatage de l'envoi
statutENUMENVOYE / RECU / LU
Note : Les fichiers échangés sont sauvegardés sur le disque du serveur (dossier uploads/) et ne sont pas stockés en base de données. Les transferts de fichiers sont limités à 10 Mo par fichier.

7. Protocole de communication

Tous les échanges réseau utilisent la classe Packet, sérialisée avec ObjectOutputStream / ObjectInputStream. Chaque paquet contient un type (String) et une data (Object sérialisable).

Types de paquets

LOGINClient → ServeurTentative de connexion
REGISTERClient → ServeurInscription d'un nouveau compte
LOGOUTClient → ServeurDéconnexion propre

NEW_MESSAGEServeur → ClientPush d'un nouveau message reçu
GET_HISTORYClient → ServeurDemande de l'historique
DELETE_MESSAGEClient → ServeurSuppression d'un message
MESSAGE_DELETEDServeur → ClientNotification de suppression
SEND_FILEClient → ServeurEnvoi d'un fichier

8. Interface utilisateur

Écran de connexion

L'écran de connexion permet à l'utilisateur de saisir son nom d'utilisateur, son mot de passe, et l'adresse IP du serveur. Un lien vers l'écran d'inscription est disponible pour les nouveaux utilisateurs. En cas d'erreur (mauvais mot de passe, serveur inaccessible), un message explicite s'affiche.

Écran principal de chat

L'écran est divisé en deux zones :

ZoneContenu
Panneau gauche (sidebar) Liste des conversations passées triées par date. Chaque entrée affiche : indicateur en ligne (🟢/⚫), avatar + nom, aperçu du dernier message, badge de non-lus. Bouton 🌙 pour basculer le thème.
Zone centrale (chat) En-tête avec le nom du contact, zone de messages défilante avec bulles alignées (droite = envoyé, gauche = reçu), indicateur de frappe, zone de saisie avec bouton fichier 📎.

Design — Thème Nature

Le design s'inspire de la nature avec une palette de couleurs vertes :

  • Vert foncé forêt #1b4332 — entêtes, boutons principaux
  • Vert moyen #2d6a4f — éléments interactifs
  • Vert clair #b7e4c7 — bulles de messages envoyés
  • Blanc naturel #f0f7eb — bulles reçues, fond sidebar

9. Guide de démarrage

Prérequis

JDK 17+ MySQL 8+ Maven 3+ NetBeans ou IntelliJ

Configuration de la base de données

-- Créer la base de données MySQL
CREATE DATABASE messagerie CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Les tables sont créées automatiquement par Hibernate au démarrage

Modifier le fichier hibernate.cfg.xml avec vos identifiants MySQL :

<property name="hibernate.connection.url">
    jdbc:mysql://localhost:3306/messagerie
</property>
<property name="hibernate.connection.username">root</property>
<property name="hibernate.connection.password">votre_mot_de_passe</property>

Lancement du projet

1
Compiler le projet
Dans NetBeans : Shift + F11 (Clean & Build)
En terminal : mvn clean package
2
Démarrer le serveur
Exécuter Server.java (clic droit → Run File dans NetBeans)
Le serveur écoute sur le port 5000
3
Lancer les clients
Exécuter MainApp.java sur chaque machine
Dans le champ "Serveur" : saisir l'adresse IP de la machine serveur
(ou localhost si on est sur la même machine)
4
Créer des comptes et discuter
Chaque utilisateur s'inscrit avec un nom unique et un avatar emoji.
Les conversations s'affichent automatiquement dans la sidebar.
⚠️ Important : Un seul serveur doit tourner. Tous les clients se connectent à ce même serveur. Personne B ne doit pas lancer son propre serveur. Les deux machines doivent être sur le même réseau local (Wi-Fi).

10. Conclusion

Ce projet nous a permis de mettre en pratique de nombreux concepts fondamentaux du développement logiciel Java :

  • Architecture Client-Serveur avec sockets TCP et multi-threading
  • Sérialisation Java pour le transport d'objets sur le réseau
  • Hibernate / JPA pour la gestion de la persistance des données
  • JavaFX pour une interface graphique moderne et réactive
  • Programmation concurrente (threads, Platform.runLater, files d'attente)
  • Gestion d'état en temps réel (statuts, accusés de lecture, indicateur de frappe)

L'application est fonctionnelle et implémente toutes les fonctionnalités d'une messagerie moderne : envoi de messages et fichiers, historique des conversations, notifications en temps réel, accusés de lecture, indicateur de frappe, mode sombre et statut de présence.
